# Mooltitool

A shelf of small apps on one screen.

## What it does

The start screen is a grid of tiles. Each tile opens its own screen: a restaurant check, a converter, an RGB color, flags, rock-paper-scissors, sleep, words, expenses, a moon, animation, habits, a coin, a timer, books, flashcards, resorts, a welcome page, and dice.

The Life tile opens areas, goals, tasks, and habits.

Most tiles follow exercises from the 100 Days of SwiftUI course.

## Stack

SwiftUI, Core Data.

## Run

```bash
git clone https://github.com/dpogonia/Mooltitool.git
cd Mooltitool
open Mooltitool.xcodeproj
```

Run the **Mooltitool** scheme on an iPhone simulator.
