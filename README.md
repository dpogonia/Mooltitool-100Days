# Mooltitool

Полка маленьких приложений на одном экране.

## Что умеет приложение

На старте сетка из плиток. Каждая открывает отдельный экран: счёт в кафе, конвертер, цвет RGB, флаги, камень-ножницы-бумага, сон, слова, расходы, луна, анимация, привычки, монета, таймер, книги, карточки, курорты, приветствие и кости.

Плитка Life открывает сферы, цели, задачи и привычки.

Большая часть плиток повторяет упражнения курса 100 Days of SwiftUI.

## Стек

SwiftUI, Core Data.

## Запуск

```bash
git clone https://github.com/dpogonia/Mooltitool.git
cd Mooltitool
open Mooltitool.xcodeproj
```

Запустите схему **Mooltitool** на симуляторе iPhone.
